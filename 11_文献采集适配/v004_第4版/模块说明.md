# 11 文献采集适配 · 第4版候选摘要模式

候选由 [04/v009](../../04_议题文献与现实/v009_第9版/模块说明.md)加载。复用生产 11/v003 的既有正常 CNKI 浏览器接口、摘要解析、目标刊种子以及原子 JSON 写盘。增加《社会学研究》官方公开 HTML 来源。知网在合法正常访问可用时负责六刊查询；其不可用时，公开备选目前仅覆盖《社会学研究》。在记录层严格核对实际刊物，查询命中不代替六刊来源确认。

- 主题语句经有界词表生成相关中文和英文检索词。分开查询扩展与固定主题匹配。当前相关性是可解释的词面规则，边界候选记 `needs_review`，不计入 100。后续语义分析消费同一矩阵。
- 分别记录命中记录、已取到的有效来源摘要、去重有效摘要及相关摘要。不要求每刊单独配额。访问失败、覆盖不足及总量不足均保留。
- 核标题、刊、年份、规范 DOI、作者、原始摘要定位及出处。DOI 优先关联，另用期刊/规范标题/作者/年份或同源身份合并。跨源发现合并并留来历，身份冲突隔离，已成功处理的同源请求优先复用。
- 同一任务在检索和摘要请求前后留事件和原子检查点。操作系统文件锁防并发写入，暂停/中断后复用页和摘要，未确认请求计入预算。访问与布局限制按提供方停止。暴露费用只在可靠凭证存在时填，本版实际费用未知。
- 摘要工作只调用检索和摘要详情，拒绝 PDF/下载 URL，不建立机构登录。全文阅读及分析属于别的阶段。生产 v003 的正文采集不变。

入口及现场验收见 04/v009 模块说明。运行资料中的来源网页、原始摘要和浏览器状态都留在本地，发布分支不包含它们。
