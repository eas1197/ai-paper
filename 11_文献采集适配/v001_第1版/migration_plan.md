# 旧知网爬虫迁移 · 第1版

已只读检查readme.md、requirements.txt、搜索入口和下载入口；本轮没有运行爬虫或修改原文件。

| 现状 | 对当前需求的影响 | 改造 |
|---|---|---|
| 浏览器与保存路径硬编码为其他机器目录 | 本机不可移植 | 统一project_config和提供方配置 |
| 关键词集合与数量写死，默认只取5条 | 无法表达议题/期刊/年份/100摘要 | QueryPlan配置与检索日志 |
| 搜索输出标题/年/URL分隔行，下载入口按整行URL处理 | 两脚本交接不兼容 | 标准题录Schema与显式兼容导入 |
| 只抓文章链接和日期 | 不足以做关系/边界图谱 | 摘要来源与字段抽取接口 |
| 重复页与论文缺少稳定去重 | 容易重复计数 | 来源唯一号/DOI/规范化题录去重 |
| 页面无验证码就计下载成功 | 登录页或未下载也被计成功 | 文件完成、PDF可读、身份和哈希验证 |
| 反复刷新、模拟真人、隐藏webdriver | 不符合稳定授权采集设计 | 删除这类逻辑，使用正常授权入口 |
| 下载/失败状态仅日志 | 难恢复、难复核 | 每论文检查点与结构化错误码 |

## 分三次实现

1. 第2版：先做Zotero/CSV/RIS导入和统一Schema；用真实5篇验证身份和状态。
2. 第3版：接授权摘要导出/期刊公开页；完成100摘要检索清单和去重。
3. 第4版：增加获授权全文解析/下载与断点；通过25核心全文验收。

原始文件、机构权限和会话由用户环境提供；缺权限记录access_denied，不以自动刷新或验证码规避补足。
