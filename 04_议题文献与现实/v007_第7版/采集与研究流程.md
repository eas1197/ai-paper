# 从现实情境到文献、问题与假设

04第7版、05第4版、11第3版共同工作。04负责六刊联网来源、摘要与入选文献，05在此基础上提出和验证候选研究问题。

## 写论文时的顺序

1. 从现实/国家政策或主题内理论线索启动，区分主题、议题、问题。教育→教育与阶层→某类家庭资源通过高中分流与最终教育结果的关系只是层次示例，不是用户默认课题。
2. 初扫政策、近三年新闻和权威文献，比较候选议题的现实/理论价值、已有解释、数据条件与可研究性。选一版暂定议题，允许后续修改，不先锁死假设。
3. 在暂定议题下联网检索六刊，逐条保存刊载页和查询凭据。只看公开摘要或片段的阶段可以设置 `download_scope=none`。需要批量归档时用 `all_related` 取得可下载的相关文献，或用 `core_only` 在摘要筛选后取得25篇入选全文。
4. 逐篇读摘要，记录X→Y、X→M→Y、X×Z→Y、反向、非线性、时序和共同条件，以及概念原意、对象、地区、时期、制度、测量、数据和设计。摘要未报告的写未知，不由缺词宣布理论不存在。
5. 归纳2—4条可修改的路径和联系。将全部已读且确认相关的六刊摘要一起比较，按相关性、理论代表性、设计和时效选择25篇。记录经典、近年和相反观点的审读情况。
6. 阅读25篇入选文献的全文，核实原问题、关系、范围、机制、设计、结果和限制，形成逐篇对话矩阵与拟引用位置。程序支持输出候选参考文献JSON、BibTeX和RIS。全文查证后按正文论点选择引用。
7. 05区分两个触发：R=现实观察与原理论预期的张力，T=既有解释尚未覆盖的重要同层级关系。两者都交代现实制度情境，T无需虚构理论冲突。
8. 分别审查四路推进：现实解释不足、同层级补充、适用条件扩缩、关系方向/形式/过程修正。逐项与原文对话，保留什么、改变什么、为什么重要、预期如何、什么结果会反驳、还有哪些替代解释。允许某路没有合格候选，也允许全部不合格。
9. 核对问卷/代码本的测量和时序、控制变量因果位置，分析前冻结。引言交接按国家政策依据→具体情境→理论预期或未解释处→具体问题组织。政策不能牵强附会，热点不能替代识别。

## 统一命令

复制templates/network_workflow_input.json到项目内自己的输入目录，填写宽泛主题及正常访问依据。初扫phase=scan，主题即可，queries可由主题自动生成；聚焦phase=focused时补暂定issue/同义查询式。没有自动默认“教育”课题。

```powershell
$entry = '.\04_议题文献与现实\v007_第7版\tools\research.py'
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action plan
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action login
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action collect
```

login会打开正常Chrome专用会话，用户正常登录/核实机构权限后按Enter关闭；浏览器会话保存在该采集job的_private，不复制系统浏览器或原项目的凭证。遇登录、验证码或拒绝访问立即停止；完成正常访问后使用`--action resume`，不会自动刷新挑战或购买文章。

初扫后由Skill/研究者比较议题，再把collection.phase改为focused、填写issue。配置变化自动使用新job目录，不能把初扫20篇当作100篇完成。默认检索六刊。摘要确认相关后参与25篇筛选，关键词排序只提供审读优先级。

```powershell
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action context
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action rank
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action core
python $entry acquire --input '.\自己的输入.json' --run-id my_study --action bridge
```

context在初扫时可用宽泛主题、聚焦后用暂定议题搜索政策/近年新闻并归档原正文；检索服务失败可在collection.context_sources指向官方URL清单，字段type=policy/news、url。默认原始来源域名gov.cn/news.cn/xinhuanet.com/people.com.cn，新增权威来源通过Python提供方显式配置。未知发布日期、事件日和政策现行性保留待核验，不能仅据RSS认定。

rank输出候选排序，不自动证明“最权威25篇”。未读摘要时仅生成词项命中优先级；实质筛选由collection.screening_file输入逐篇摘要复核，字段paper_id、decision=included/excluded、review_status=verified、reviewer、read_at、reason、scores（relevance/theory_authority/design_quality/journal_authority/recency均0—5），可加perspective_tags=[classic/recent/counterevidence]。相关性为零者排除；权威或时效不能覆盖不相关。模型可以建议评分，仍保留复核归属。

core下载已选候选（selection_file可指定，默认读取core_selection_proposal.json）。至少25篇、必须是当前检索ID；不足保留缺口。all_related已成功下载的不重复获取。文件哈希变化时保留旧件另存重试；题名或作者匹配失败为identity_needs_review，不计成功。扫描件需正常OCR/人工核查。

bridge将采集结果接成可直接供04/05执行的workflow_collected.json、逐篇reading_tasks.json和候选参考文献文件；保留原有本地文献源和标注，每次新建handoff_inputs/attempt_NNN，不覆盖手工研究记录。所有新摘要与全文的阅读状态均为not_read；取得文件不自动认证已读。

填写/复核标注后，用bridge返回的workflow_input路径运行`run --input <该路径> --run-id my_study --stage both`。G4未过时05可整理探索性候选与反馈，但不能正式放行；quality_review仍须绑定当前内容哈希。旧使用说明中“默认没有网络采集”描述的是第4版；第5版通过显式acquire动作接入11，普通run仍只处理锁定本地证据。

## 实际目录和权限

采集位置为既有run_store下`<run_id>/acquisition/cnki_<配置哈希>/`，题录在literature/metadata，全文在literature/fulltext，状态在checkpoint.json、downloads.json、search_log.json，政策新闻在context。原E:/文章/cnki爬虫、Zotero和调查数据只读。

Driver版本必须与Chrome兼容；配置driver_path可指定正常安装的Driver，不填交给Selenium Manager。旧目录Driver不自动运行。本机探测时Chrome为157、旧Driver为143，不应直接沿用该旧二进制；环境探测细节见outputs/live_probe.json。真实CNKI HTTPS请求有证书验证失败，本轮没有登录机构账号或完成真实下载验证，也没有关闭TLS验证。离线测试通过不能称为真实知网端到端通过。
