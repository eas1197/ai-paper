# 04 第12版 · 九刊 Codex 原生检索候选

本模块保留独立的 `paper_codex_native` 实验入口，但**默认检索目标为0篇**：`native_request.json` 与 `native_100_request.json` 均设置 `target=0`、`max_batches=0`。默认运行时，`native_library.py` 在调用 Codex 搜索器、摘要接收器或创建作业目录之前返回 `status=disabled`，不启动搜索、不创建批次、不生成空壳文献记录。

九刊白名单仍与原 v009/v3.2 `search_policy.json` 完全一致：中国社会科学、社会学研究、社会、探索与争鸣、中国青年研究、经济研究、管理世界、American Sociological Review、American Journal of Sociology。提示词、Schema、注册表及11/v007底层适配器继续保留，因为3.x选题流程和5.0 Chat搜索仍复用其中的共享检索合同或来源处理能力。**本次0篇设置只禁用04/v012独立采集入口，不改变3.x Codex搜索、ChatGPT内置联网搜索、九刊政策或原有配额。**

默认运行：

```powershell
python -B -X utf8 .\04_议题文献与现实\v012_第12版\tools\native_library.py --profile paper_codex_native --work 00_项目控制/v006_第6版/outputs/codex_native_runs/attempt_001 --theme 教育分流
```

预期只返回 `disabled / target=0 / count=0 / batches=[]`，不会执行搜索。若未来需要独立实验，必须显式复制配置并将 `target` 与 `max_batches` 设置为正数，使用独立实验目录；该操作不自动进入5.0生产文献库，也不构成生产流程启用。

历史实验记录、20篇/100篇原设计、来源核验、去重和交接代码均保留，不删除、不覆盖。
