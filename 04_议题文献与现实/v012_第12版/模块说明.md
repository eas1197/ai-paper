# 04 第12版 · 七刊 Codex 原生检索

新检索入口由七刊候选注册表启用。现阶段使用教育分流的20篇摘要验收入口，首次只输入主题。检索、关键词调整、页面阅读、研究相关性由 Codex 搜索会话决定，Python 保存凭证与去重结果。

```powershell
python -B -X utf8 .\04_议题文献与现实\v012_第12版\tools\native_library.py --profile paper_codex_native --work 00_项目控制/v006_第6版/outputs/codex_native_runs/attempt_001 --theme 教育分流
```

通过 `--resume` 恢复同一作业的已提交批次；`--verify-only` 重新核对留存事件、结构化答复、摘要和去重结果并生成摘要矩阵。原来源摘要保留定位及短摘，摘要概述标明为转述。若事件只证明 URL 被发现，短摘未出现在日志返回中，则保留为需要来源人工核验的记录。

通过20篇来源复核后，可以用 `--config <native_100_request.json>` 和 `--expand-from <20篇作业目录>` 在独立目录验证100篇。首批20篇的复核结论必须绑定原集合哈希。检索会话只见本作业已接收的排重题名。

`--verify-only --handoff-check` 用已经放行的摘要候选检查生产04的题录入口，输出实际导入结果和衔接阻塞。准备资料、摘要已取得、原文实读、G4正式放行分开记账。
