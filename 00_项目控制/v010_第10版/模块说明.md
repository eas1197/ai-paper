# ai-paper 5.0 · 全系统研究—写作整合候选

版本：00/v010（开发候选）｜2026-11-23｜开发分支：`dev/v3.1-abstract-acquisition`。

## 目标与模块路由
将研究选题、现实事件与跨事件比较、文献初查与补查、学术问题和方法分流、经验材料及分析、以及写作与审核对齐为可追溯同一run_id的过程。
**历史定量路径不变**：选定`quantitative`时仍须返回生产07/v014及既有定量分析；本轮允许记录`sta_analysis_status=not_executed`，不能报G6或正式G7通过。
**定性路径**：选定`secondary_interviews`或`online_qualitative`时复用06/v005框架与分析矩阵的学术任务、07/v015的定性七章结构、07/v016 ai-writer 4.0逐段学术语言与证据自检。03/v004（15项ST风格）+03/v005（按段功能映射）+03/v003（论证规范）不改旧库。

此v010是**Chat原生研究的可复现阶段编排器**，并非已把原v009 Codex CLI搜索器改成ChatGPT联网工具：ChatGPT亲自通过自带网页工具完成文献/社会材料检索，再将真实、带来源的结果写进相应阶段JSON；v010 Python只验证顺序、证据结构、阶段哈希并交给v016。它本身不会检索或自动调用LLM，也不会执行Stata、发布论文或发起API计费。

## 14个阶段
`topic_candidates → reality → event_comparison → explanation_exchange → literature_initial → preliminary_review → research_design → literature_supplemental → final_review → empirical_materials → analysis_matrix → writing_packet → manuscript → writing_review`。

每阶段`ingest`写入不可覆盖的`stages/序号_阶段.json`、写入输入与快照SHA-256；`status`检查文件未被改写、报告实际进度与缺额、方法及学术状态。初查与补查实验目标5+5，严格九刊或确认为顶尖专刊范围仍单独审核，数量达到不代表合格；5+35正式量不降低。事件与文献去重；同一媒体的不同场所不是独立媒体证实。没有真实独立审查回执时，Chat同一模型角色质疑只登记`same_model_adversarial`。非正式实验仍可探索性继续形成文稿，但不表示任何学术关卡已通过。

## 调用

```sh
python 00_项目控制/v010_第10版/tools/ai_paper5.py init --work <新实验目录> --run-id rider_access_20261123

# 逐阶段按上述顺序导入真实Chat研究文件（严禁用自编假引用补齐）
python 00_项目控制/v010_第10版/tools/ai_paper5.py ingest --work <实验目录> --stage topic_candidates --input <对应输入.json>
# 后续13阶段相同，一项一项记录；保存来源的原始URL、日期、定位与材料边界

python 00_项目控制/v010_第10版/tools/ai_paper5.py status --work <实验目录>

# 在完整仓库环境中，仅对真实记录的定性writing_packet调用原v016：
python 00_项目控制/v010_第10版/tools/ai_paper5.py writer-prepare --work <实验目录> --packet <writing_packet.json>
python 00_项目控制/v010_第10版/tools/ai_paper5.py writer-submit --work <实验目录> --packet <writing_packet.json> --manuscript <正文.md> --claims <主张证据台账.json>
```

注意：`writer-prepare`、`writer-submit`要求完整仓库存在；即使它们运行成功，也只能产生探索性写作待审结果。目前没有获得在完整仓库环境中实测V16调用成功的凭证，不能宣称正式写作入口已全链路验收。

## 风险与版本关系
此版本**没有取代**正式生产v005控制器、v009学术门禁、03正式G3、06数据/材料验收或07/v014定量入口。逻辑上已经串联阶段与V16调用命令，研究记录采用Chat原生工具检索，生产级自动化和独立学术审核仍待开发/认证。不能将技术`technical_complete=true`等同于学术`passed`。所有来源有权使用的脱敏摘要、论断和出处可以公开；个人数据、后台日志与没有获得的采访原件不得编造或上传。
