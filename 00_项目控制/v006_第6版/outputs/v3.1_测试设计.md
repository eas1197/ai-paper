## 二、真实正向业务 U01

启动先冻结研究范围、来源授权、运行预算、候选注册表版本和放行人。主问题可来自教育或另一真实定量社会学课题，须在候选阶段用文献和证据独立说明价值。双窗口题先用于回放。只有独立审查发现它符合主问题要求、题项与分母可核且取得合格全文时，才能继续作正向题。选题方向由证据决定，不能为了验收硬给 READY。

| 次序 | 交付物和放行证据 |
|---|---|
| 1 自主选题 | 初始范围、证据链、主问题与诊断池、近似研究表、变更链、READY 与候补去向，冻结候选版本引用。 |
| 2 G4 | 指定六刊、约 100 有效联网摘要、25 篇实际全文及阅读对话、反例及现实政策证据、有效 manifest/bundle 和人工或研究复核。目前教育历史 1/100、0/25 只能用于负向。 |
| 3 S07／G5 | 独立实质反方审查、报告与当前 G4 和问题版本绑定、正式凭证、目标量和设计、G5 `passed` 和事前冻结。 |
| 4 06／07 | 06 按原方法要求生成真实可复现结果、诊断和交接，G6 通过。07 检查实际有效 G2—G6 并生成可核冻结写作包和写作任务。检查端到端版本和表证可回溯，验收可止于写作交接。 |

G4 访问受限、核心全文不足、没有合格主问题、G2/G3 或 G6 未放行时，按首次失败阶段写 `blocked`、实际数、原因、权限条件和可恢复材料。每次新 attempt 用同 run 和有效快照，学术验收在可核证据支撑时由合格复核者确认。

## 三、同材料配对比较 U02

基线冻结 v3.0 教育输入和阶段产物。先做确定性回放，核 T01–T16 的新增不变量。再以同题域、同一来源包、相同主研究角色与审查设定、对等预算预先固定比较协议，独立审查时隐藏版本名。审查至少记录① 主候选是否混入诊断／重复② 学术或现实判断改变的具体理由③ 原文命题和反证能否回查④ 正式交接是否等同⑤ 有效增量和返工。定性理由要逐题定位。至少用教育案例和一个不同结果的比较案例；小样本结果只作改进证据，不推断普遍优势。

通过标准是关键负向全部正确拦截，合格主问题无无关规则新增阻塞，源文献／谱系／题目版本可追，盲审能解释新增的实质收益；另用 U01 验真实正向。运行成本按实际派发、提供方请求、输入输出 Token、费用和人工时间分别比较。一般路径不得引入固定额外探索审查；付费实证漏项就给不可比声明，不能靠内容更精炼推导省钱。单列研究方与审查方可比工作量、提前停题所节省的工作，并记录证据复用是否公平。全流程启用条件还需兼容性和真实正向证据，两类结果按矩阵单独记载。

## 五、A02 独立门禁用例

先构造技术夹具，准备有效 G4、原正式审查覆盖、有效回执和拟冻结输入。每例只改指定输入，余项固定。除 A02-T01、A02-T02 在满足下列条件后可沿用报告，任何涉及实质变化的旧回执本身不得通过。夹具只验证技术行为。

| ID | 单项变化 | 期望与可查结果 |
|---|---|---|
| A02-T01 | 排版、白名单标点或空白；另以会改变限定范围的标点为反例。 | 机械等价 A，完整 S07 调用为 0；变更留档，必要时重签当期回执。反例拒绝 A。 |
| A02-T02 | 变更一个常规处理步骤但不改变样本、目标、主要结局，或另加探索输出。 | B。G5 保存自身通过依据后可复用报告；误改选样即不得按 B 放行。 |
| A02-T03 | 变更非核心证据定位或一项非决定性局部证据。 | C。仅有旧 PASS 拒绝；独立复核明确受影响与继承清单，新快照及 PASS 有效后再签新回执。复核超范围无法闭合则升级。 |
| A02-T04 | 变更适用研究对象。 | D，原审查失效，完整独立 S07。记录对象差异。 |
| A02-T05 | 实质变更分母或比较对象。 | D，旧回执拒绝，记录队列差异及原因。 |
| A02-T06 | 实质变更主要结局定义。 | D，旧 PASS 失效，记录相关观察及测量覆盖条目。 |
