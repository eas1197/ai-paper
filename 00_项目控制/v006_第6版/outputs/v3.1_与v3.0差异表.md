# v3.1 与 v3.0 差异表

2026-11-21。下列差异均为拟实施规格。根据[真实复审](v3.1_改造任务书.md#一现行基线及复审)确认现有能力，变更、保留、废止均通过后续验收再生效。涉及旧历史时仍按其冻结版本解释。

| 项目 | v3.0 实际规则或能力 | v3.1 决策及理由 | 对模型的影响 | 任务 |
|---|---|---|---|---|
| 发现机会 | 现实、理论、文献线索，Sol 分析价值与后续行动。 | **保留**。继续允许通过、退回、停止；明确事实、待解释现象、政策目标与研究者推测及各自的时间范围。为批准机会登记去向，避免宽主题检索把范围随意缩窄。 | 无固定增量 | A01、P0-01、P1-01 |
| 候选池 | Q0 和 Q2 同属 `questions`，程序只验引用和祖先。 | **修改**。五种角色与父版本。主池单列，辅助作为诊断、可行性或稳健性，不给多样性加分。诊断能改写父问题。 | 0 次额外派发 | P0-01 |
| Q→X→C→Q | 稳定 ID、理由、改问链已存在；旧问可回查，但同 ID 跨轮语义无强制比较。 | **保留原链并新增**不可变问题版本、差异和分支处置。区分理论、机制、设计、测量、情境和重复验证；写清不同答案的知识差异。 | 0 次固定增量，决定性缺口才补查 | P0-02 |
| READY／边际效益 | READY 可进 formal，程序记 `quality_met`，Sol 有继续、分支、停止。 | **修改**。保留探索放行与停题，状态明确为 formal search eligible；记录最近似研究、查证目标、成本和停止条件。**废止**把 READY 或口径变化当作已经有创新的解释。 | 保留现有独立角色和阶段预算 | P0-02/P1-01 |
| 文献结构 | 04/05 已保留关系、证据、四路、意义、全文对话和目标量。初查解释与近似对比薄。 | **保留既有检查，扩充初查与正式全文字段**。把作者命题、机制、证据、竞争解释和预期差异组织进现有对话矩阵，不重复造一套综述。 | 同一次阅读与裁决内完成 | P1-01 |
| 证据位置 | 已验路径、短摘、页码、哈希。审查只确认 ID 与非空定位，笔记能成为短摘锚。 | **修改**。核与原文、页序／显示页和审查引用一致；推断必须有基础证据链；人工待核有回执。**废止**仅凭定位笔记验证直接原文主张。 | 0 次额外派发，疑难源人工复核 | P1-02 |
| S07 与 G5 | 已有 `final_gate` 快照与 ID 检查，G5 自有质量硬门槛；正式回执尚非必经条件。 | **新增**正式报告与 attempt 凭证闭环。为 v3.1 在 `stage05` 强制核门禁，防止直接调用和改题绕过。既有 G5 复核、冻结和探索路径保留。 | 完整正向路径需已计划的正式 Sol；合用一次实质复核 | P0-03 |
| 调用与预算 | 每条 `record` 至少一次 `model_calls`，人工回填与真正请求混用。 | **修改**。拆派发、提供方请求、裁决和检索批次。**废止**每条裁决固定报一个真实调用。取原始凭证，缺测标未知；预算预留、去重、失败明确。 | 0 次额外派发，可减少重复请求 | P1-03 |
| G4/G5、下游与版本 | 六刊、约 100／25、正式复核与上游哈希；生产由注册表启用。 | **保留**标准与旧历史，v3.1 另建候选对象、注册表和兼容读适配，先验接口再决定是否改 06/07。无真实正向证据时不启用。 | 沿用原下游执行和复核预算 | P2-01/SYS-01 |
| 业务和成本结论 | 教育运行实证了摘要复用及失败拦截；D08 有有限内容对照，费用未测。 | **新增**真实正向、负向、历史兼容及同材料配对协议。**废止**用夹具通过代表真实验收，或把内容完成等同省额度。 | 一次真实业务运行，条件允许再做配对；实际用量看凭证 | P2-01 |
| 题句与方法口径 | v3.0 验证问题文本和 `population` 等字段非空，教育 Q1 文本与总体字段有差异；现行 05 已检查正式目标量、测量和设计。 | **新增** S03 前置适配检查和范围比对；保留 05 正式复核。定性、历史、比较和混合用各自规则；正式生产范围仍按根规范。 | 0 次固定新增派发 | A01、P0-02 |
| S07 变化和重审 | v3.0 已能检查当前 G4 快照、ID 和正式裁决，缺结构化覆盖及按影响范围的失效规则。 | **新增**五块覆盖、A/B/C/D、快照与实际冻结内容比对。回执绑定变化使旧回执无效；审查报告可按等价、自查、定向或完整复核恢复资格。历史凭证保留。 | A/B 不追加；C 定向；D 完整 | A02、P0-03 |
| 原始需求和授权 | 上一轮 v3.1 矩阵指原委托章节，任务书和矩阵对第一批依赖说法不一致。 | **新增**原始逐字快照与 SHA-256；**修改**第一批只做 P0-01、P0-02，第二批开始 P1-02 基础接口，业务开发和启用各自授权。 | 0 | A03、SYS-01 |
