## 调用能力实测

Windows 的 `codex-cli 0.171.0-alpha.13`，在当前订阅用户环境执行 `codex login status` 显示 `Logged in using ChatGPT`。小范围实际探测的事件包含一次针对文档的原生搜索、一次网页打开以及对应的真实 URL。命令使用全局 `--search`、`exec --ignore-user-config`、只读、临时会话及 JSONL 输出。正式候选调用也清除继承的 API key 环境变量。CLI 的事件名为 `web_search`。这一证据证明可实际完成原生搜索及网页访问，工具表面名称和桌面对话有所不同。[Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)

## 工程实现

论文集合保留题名、作者、期刊、发表年、DOI（已证实才保留）、出处、原摘要短摘和定位、摘要转述、学术相关性理由及其本次工具事件。程序复用身份匹配规则，对七刊做跨来源去重和冲突隔离。逐批将答复和原生搜索事件写入独立目录，接收端独立重算摘要、来源回链、分组和计数。

日志能证明链接由原生工具返回，只有机器日志里能定位到短摘时才标记为机器直接复核。其他摘要通过来源复核判定。拿到检索 URL 或取得结构化文章数组，都不直接视为20篇学术验收通过。

## 真实验收

现场目录为 `codex_native_runs/education_tracking_20261121_001`。

### 20篇先行验收通过

- 启动输入仅有「教育分流」、七刊范围和空排重清单。一个真实 CLI 会话，51 个原生网页工具完成事件，其中20个以搜索动作返回，其余包含页面读取与定位。完成的事件、答复和复核分别在 `batch_001/events.jsonl`、`batch_001/response.json` 和 `pilot_review.json`。
- 结构化结果有24条。两条摘要链接未能回链本次工具日志，程序保留为未确认。22篇去重候选经过来源和内容复核后，20篇计入。另有一篇原刊摘要页面复核未打开，一篇主要考察毕业意向，均留在排除记录。
- 20篇中，《社会》12篇、《社会学研究》5篇、《中国社会科学》3篇。曾检索其他指定刊物；本次20篇未要求每刊各有入库。7篇原摘要短摘可从记录的原生工具返回直接定位，其余经公开来源核对。摘要转述和原文短摘分字段保存。
- 自主检索从「教育分流／普职分流」扩到「重点中学／升学关口」，再跟着文献扩到「高考分数阈值／录取不确定性」和「研究生教育机会」。发现页、摘要页以及证据位置分别记录。[《社会》普职回报原刊摘要](https://www.society.shu.edu.cn/CN/abstract/abstract7154.shtml) · [《社会学研究》高考录取原刊提要](https://shxyj.ajcass.com/Admin/UploadFile/20130926008/2020-01-29/Issue/l5gltkdp.pdf#page=1)

### 论文工作流衔接预检

用实际20篇运行了现行04模块的 `LocalLiteratureProvider`，20/20题录导入，原 ID 保留，含12篇《社会》。生成 `handoff_preflight/` 的题录、摘要阅读任务和预检报告。正式接收尚缺原生检索凭证到G4合同的映射，现行G4仍内置原六刊范围，25篇核心全文等门槛仍适用。此次取得的候选摘要没有转记为生产G4合格摘要，未执行G4、05或写作。
