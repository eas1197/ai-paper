## 一、结论

**主要问题出在定题前的 S02—S03 与初查深化的 S05—S06。系统把「有区别的候选」执行成了「有区别的产物」，又把「测量更精确」当成了足以优先推进的研究增量。** Q2 是对 Q0 的测量核查，却与 Q0 一起占据候选位置。Q0 遇到真实的文献重复风险后，确实演化为更具体的 Q1，但旧的学术问题「家庭背景怎样参与教育分层」被换成了「分组差距对观察窗口是否敏感」。这个问题有观测和设计价值。若要成为教育社会学主问题，还需说明哪种知识判断会因结果而改变，以及怎样区分真实升学过程和记录形成过程。

**READY 的依据足以做一次有明确目标的查重，作为唯一方向投入完整 G4 的依据偏弱。** S01 对政策证据的克制、文献发现重复后允许改问、Sol 对观察边界的反对意见、G4 的正式计数和 G5 的拦截都值得保留。真实流程停在 G4 待审、G5 未冻结，未观察到低质量题目最终放行。程序能让准备材料和早期判断跨阶段保留，但目前对候选退出、问题版本和 S07 正式审查的衔接约束不足。[第三轮裁决](topic_runs/topic_v3_education_live_20261120/round-00000003.json) · [G4 报告](../../v002_第2版/runs/topic_v3_education_live_20261120/stage_04/attempt_003/gate_report.json) · [G5 报告](../../v002_第2版/runs/topic_v3_education_live_20261120/stage_05/attempt_003/gate_report.json)

## 五、根本原因与必须修改的规则

1. **先校验研究问题类型，再比较质量。** 建议 S02/S03 给每条分配「主问题」「测量诊断」「数据搜集任务」之一并记录父级。允许有理论或现实意义的描述性研究，要求它事先写清关键未知、结果将改变什么判断。Q2 应服务于 Q0／Q1 的适用范围或敏感性，不能再当另一条主问题给多样性加分。
2. **重排价值与可行性的顺序。** 先写出研究对象、要解释的社会现象、至少两个实质不同的解释或一项有依据的异常，再用数据核可观察预期。无法形成竞争解释时可保留理论或现实命题未解，不能用同波次或换口径硬凑创新。对每条经批准机会和问题填「深化、合并、转诊断、暂缓、淘汰」及理由。无需为凑数硬留多个方向。
3. **给 Q0→Q1 增加变化核验。** 每次追问同时登记「原命题与反证」「新回答能排除什么」「实际可观察量」「贡献暂定类型」。同一研究的不同窗口通常是设计或测量增量。若要以此主张理论增量，应先说明竞争预期，例如家庭约束集中在毕业当年和学校选择持续分层会分别预测什么，且记录机制产生的同样模式也要可识别。这些是下一版示范命题，现有运行没有证据确认其成立。
4. **用证据强度决定下一步。** `READY` 建议显示为「可进入正式检索」，质量结果另标「理论增量未证实」「边界待核」等。遇最相近研究只读摘要、关键分母或时间未明，给带检索目标和停止条件的定向初查，或以明确的查证任务进入 G4，不授予创新判断。若另有解释路线或最低成本的鉴别仍可做，应记录为何暂不尝试。G4 文献不足仍停在原关口。
5. **正式复核必须可交接、可重验。** 将候选 ID、版本、题句、固定分母、未决问题、旁支处置、初查证据及对应原文快照一起传到 G4。G5 用同一问题版本；若删去父母教育、改变结局或改动方向，产生新版本和改动理由。针对 v3 正式冻结，保存绑定当前问题版本与 G4 快照的 S07 `final` 回执。保留非 v3 和 G4 未通过时的探索调用方式。把实质缺口写成可执行反馈。
6. **把审查结构化回执和真实派发分别记账。** 一次多阶段派发可以有多份回执，复用同一宿主标识并注明共用上下文。存发起角色、模型、所见材料版本、原始返回与录入摘要；运行中缺真实用量就标未知。探索预算覆盖探索，若正式检索预算另计也要在状态中明示。正向重测、负向拦截及版本启用分别记账。上次真实复用已验 1 篇摘要，不能外推到全文正向验收。

## 六、建议的质量门槛与下一版设计

| 时点 | 新增门槛与可验证输出 |
|---|---|
| S01 → S02 | 机会卡分别列观察事实、制度目标、待解释现象、可能机制和适用时期。政策晚于队列时只标研究动机。两条线索即使共享来源，也要说明能提出怎样不同的问题。 |
| S02 → S03 | 每条主问题写比较对象、预测差异、取值足以改变的结论和所依原文。诊断题有父级并退出主候选清单。明确比较了哪些方向、哪些有证据被退回。 |
| S03 → 初查 | 题句、结构化对象、结局和窗口一致。对本例定义同一基线分母，分开已确认、类型未知、完访未确认、访谈缺失和回顾补记。只有测量可比时才比较两个窗的差距；若只采用两轮完访者，显式说明目标受限及选择风险。 |
| 初查 → G4 | 对最相近研究给可回看篇名、出处、页段及其研究单位、分母、窗口、结局和覆盖判断，分别记录读到的层级。保留最强反例或待核点、投入下一轮能排除的路径、预计成本和停止条件。查不到就允许暂缓或保留「待查重」状态。 |
| G4 → S07 → G5 | 保留原 100/25 和实读审核。正式全文复核应有同题矩阵，将观点、结果、范围、设计限制、可以比较的分歧及待判别干净分开。S07 回执绑定候选版本和现行 G4 内容；G5 依此及实质审核正式冻结。 |

优先顺序建议为 **P0** 先分开主问题与诊断，收紧 READY、候选去向和正式版本绑定；**P1** 再完善近似研究比较、原始回执及成本证据；**P2** 补正式文献的正向验收，之后才调整默认入口。下一版可用一张阶段对账表追踪机会、主问题、诊断和证据状态，避免为每次运行新建一层审批或增加固定审查轮数。

### 暂时保留的部分

- 保留现有 G4 的六刊、100／25、来源凭据、全文身份与实读要求，以及 G5 的硬拦截、内容哈希复核与允许零题通过。资源访问不足应保留缺口，不能通过降低标准解决。
- 保留哈希、同一 run ID、追加 attempt、Q→X→C→Q 的演化记录和原因，保留正式研究前的 `READY` 与 G5 冻结两级。
- 保留独立 Sol 审查、边际效益判断和停止机制。现有记录不足以把问题归因于 6.2 Sol 档位；换模型、增加智能体或单纯扩大初查量都没有解决本轮发现的结构缺陷。
- 保留教育分流及窗口敏感性作为可继续查证的候选与诊断。当前一次 G4 受阻的试跑既不能确认它有学术贡献，也不足以否定它未来能形成有意义的教育社会学问题。

以下为下一版验收设计，本次未执行。以本地原始运行的只读副本或合成夹具分别复现，每项同时核对状态、原因与证据链。

## 八、审计边界

没有实证证明该候选确实有新发现，也没有完整文献证明它已被他人回答。初查中的期刊来源、2020／2022 访谈实际覆盖与相应报告机制仍待核实。当前只有一条真实教育运行，不能推断所有学科或所有模型都存在同样的执行偏差。对 S07、S08 正向路径的结论来自源码及缺失的实盘产物，办理成功的业务验收仍待验证。
