# ai-paper 5.0：历史单 AI 自主执行层（00/v011）

**当前定位：** 历史实验实现，仅供追溯，不是当前5.0总控或推荐执行入口。保留 Codex CLI 非交互调度、预算、工具事件和续跑实验；以下命令仅用于复现历史实现。当前唯一开发候选为00/v012，原3.x学术门禁仍有效。

目标：一次启动，让一个接入的 AI 在单次运行中自主完成社会学定性研究的选题、真实网页搜索、文献核读、经验材料、理论分析、写作、技术检查及返修；不再逐阶段手工提交 JSON。保留旧 V10 的证据冻结和 V16 的真实写作器。主分支、生产注册表及定量 V14 不修改；本次不运行 Stata。

## 使用

在完整仓库根目录、本地已安装并登录 Codex CLI 的电脑（Python 3.11+）：

    codex login
    python "00_项目控制/v011_第11版/tools/ai_paper5_auto.py" doctor
    python "00_项目控制/v011_第11版/tools/ai_paper5_auto.py" run --work "00_项目控制/v011_第11版/runs_dev/my_study_001" --run-id my_study_001 --max-calls 30 --max-attempts 2

断开后用相同 run 命令继续，已经冻结的阶段不会重做。可加 --model 指定登录账户可用模型；--timeout 设置每次执行时限。原始日志、研究材料和认证数据只应保留在可信本地环境，不默认公开上传。

## 机制与边界

Python 负责下一阶段决策的约束、预算、追加记录、检查与恢复。Codex CLI 通过非交互执行、--search 的实时网页工具，执行 AI 搜索、阅读、研究和写作。要求搜索的阶段若拿不到 JSONL 真实 web_search 调用记录就拒绝登记。AI 需生成真实结果文件并符合 V10 的阶段契约；已读文献不能只提交网址。

定性写作包经 V15 检查，在 V16 生成任务，AI 按逐段任务实际写文章和 claims 台账，写作器执行技术审查；不合格则限次返修。14 阶段不准跳过或覆盖。超过预算、找不到足够证据、学术关卡拒绝、CLI 缺失、V16 拒绝时必须停止，并保留检查点。实验文献为 5+5，正式候选规范 5+35 不降低。

单个模型的反诘只能是 same_model_adversarial，同模型文章复核只能是 single_model_review；正式独立学术审查、G3 和 G7 均未验收。能生成全文也不等于研究合格。

AutoRunner 通过 adapter.invoke(stage,prompt,attempt_dir,needs_web) 与具体 AI 解耦。当前提供的是 Codex CLI 适配器，不是 ChatGPT 当前对话的内置网页搜索，也不需要另行调用付费 API。接入其他 AI 必须先实现同样的真实搜索证据与使用量审计。Codex CLI 登录、额度和网页工具是否可用，由本地账户决定。

## 已核验与尚未核验

离线模拟测试：连续执行、失败重试与恢复、无网页调用证据拒绝、禁止假读文献和伪造审查、缺 Codex 安装明确报错。它们不证明已在真实登录下连续完成14项研究。尚需 Windows 本地登录下的真实从零选题到论文验收，并进一步补齐独立学术审查与正式文献标准。
