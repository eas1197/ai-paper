## 控制工具

Python 3.10+，仅标准库。在项目根目录运行。

```powershell
python .\00_项目控制\v004_第4版\tools\project.py validate
python .\00_项目控制\v004_第4版\tools\project.py trace
python .\00_项目控制\v004_第4版\tools\project.py plan --writing-mode single
python .\00_项目控制\v004_第4版\tools\project.py plan --writing-mode three_plus_review
python .\00_项目控制\v004_第4版\tools\project.py init --run-id education_single --theme "教育"
```

初始化只建运行工作区。议题可在第4步生成，`--issue` 用于传入待核定候选。实际关卡由对应模块复核放行。
