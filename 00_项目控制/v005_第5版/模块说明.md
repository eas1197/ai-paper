# 00 项目控制 · 第5版

00 是全项目的 TRACE 管理入口，覆盖 01—09 业务关卡和 10—12 支撑模块。先读根规范，再从 [当前状态](outputs/当前状态.md) 定位当前有效工作。

- [TRACE 执行与接续](TRACE执行与接续.md)说明如何登记需求、阶段、变更、恢复点与交付。
- [模块注册表](module_registry.json)确定启用版本，[运行配置](project_config.json)确定路由及运行目录。
- [需求追踪矩阵](需求追踪矩阵.csv)承接原有 R01—R17 编号，[需求原文与变更](需求原文与变更.md)保留可取得的原文和替代依据。
- [阶段台账](阶段台账.md)保存项目级阶段目标、依赖和核验位置。每篇研究的执行与结果继续进入原运行目录的 manifest、attempt、日志与关卡报告。

配置仍使用原 v002/runs。第5版 CLI 支持原有 validate、plan、status、init、inventory，新增 trace 按需读取当前公共资源和历史运行检查点。研究运行 manifest 保持 Schema 2；原有阶段工具和数据契约继续适用。阶段报告的历史状态需结合上游依赖与哈希判断。

选题入口与完整单稿流程见[选题与自动论文流程](选题与自动论文流程.md)。阶段执行器读取原有兼容配置；本版沿用第4版业务配置、01—12的注册项和原运行目录。新增选题记录只在新运行清单中按哈希绑定。

验收包括版本和证据链接、两种写作初始化、历史运行接续及文件保留。参见 [迁移验收](outputs/迁移验收.md)。
