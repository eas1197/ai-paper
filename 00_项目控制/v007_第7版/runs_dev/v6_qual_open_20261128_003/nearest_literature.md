# 排程控制近邻相关正文核对

- Kelly 等（2011），https://pmc.ncbi.nlm.nih.gov/articles/PMC3094103/ ，“Schedule Control”第 99–109 行与测量、分析第 239–245 行。排程控制概念已明确包括何时开始、结束和白天离岗，组织文化指标亦考虑因处理私事离开而被视为不投入。纵向部门对照研究检验 ROWE 对排程控制及家庭冲突的作用。不能把“去不去办公室”或“离岗自由有差异”当新发现。
- Kelly 等（2014），https://journals.sagepub.com/doi/10.1177/0003122414531435 ，表 3 段落，第 300–319 行。STAR 同时改变排程控制和主管支持，部分员工更能在工作时段处理个人事务，居家时数变化亦报告。研究明示组织期待、互动和实践会影响工作家庭结果。候选须区分具体现场工作回合中的退出许可、代岗与评价，而非泛称组织支持重要。研究对象不同本身不构成增量。
- Roscigno 等 AJS 论文此次仅核出版方页，不以未读正文否定增量。
