# 实施路线 · 第3版

1. 一次性建设01—03：期刊库、至少20篇全文结构手册、同语料语言规则与例句。通过各自验收后发布资源快照。
2. 建立文献采集、证据链、调查元数据适配及长期方法库。方法范例可不断积累，不在每篇重找全部22类。
3. 每篇新论文执行04—06：从现实/理论线索生成并筛选候选议题，再开展聚焦检索、约100摘要、25核心全文及政策新闻核查；修订议题并形成问题假设，随后进行变量核查与实际定量分析。
4. 按配置选择07单稿，或07三稿+08评审筛选。默认single；两种都做07内必要自检。
5. 09可选，依据稿件模式接收07单稿或08优胜稿，复核候选目标刊的动态规则并生成逐刊版本。

初始化工具已支持两种计划路线。真实资源/全文/分析/写作执行器均待实现，现有模板不代表业务完成。
