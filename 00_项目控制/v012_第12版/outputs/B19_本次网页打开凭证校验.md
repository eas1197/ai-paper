## 本轮修复

1. 在 v009 event_protocol 新增 opened_event()：从本次 native web_search trace 中寻找 action.type 为 open_page 或 find_in_page、action.url 与 source canonical URL 一致、且事件含有结果的事件。
2. build_source_receipts() 不再用“URL 出现在搜索结果”作为最终来源事件；它仍先确认 URL 属于本次搜索 trace，然后必须找到匹配的页面打开事件，否则抛出错误。
3. source receipt 的 event_id/open_event_id 指向实际打开事件；记录 action_type，并将 opened 固定为 true。
4. compare_events() 要求每个 source receipt 的 opened=true、event_id=open_event_id，action_type 只能是 open_page/find_in_page；缺少 action_type 或打开凭证时拒绝。
