# B14-04｜原生检索提示词与英文期刊支持核查

**状态：implemented_unverified。** 静态调用链核查完成，04/v012 搜索提示词与输出 Schema 已修正；自动化测试属于下一子任务 B14-05，真实检索属于 B14-07，本轮均未执行。

## 结论

**九刊名单会动态进入 Codex 搜索任务，但原提示词和输出 Schema 对英文论文存在中文化限制。** 配置九刊并不自动保证英文期刊能被正确检索和接收。本轮已修复提示词与 Schema 层面的限制。

## 调用链证据

1. `04/v012/tools/native_library.py` 的 `collect()` 调用传入 `templates/search_prompt.txt` 和 `templates/native_response.schema.json`。
2. `11/v007/tools/codex_literature.py` 每批读取提示词模板，将 `config["journals"]` 以 `、` 连接后替换 `{journals}`，同时替换主题、目标篇数和排重题名。
3. 同一函数将输出 Schema 传入 `invoke()`；Codex CLI 命令包含 `--search exec` 和 `--output-schema`，并把实际提示词保存到本批次的 `prompt.txt`。
4. `observation()` 对期刊名执行九刊白名单精确匹配；题名和作者字段只要求非空/可规范化，不检查中文语言。摘要短摘只检查 8–90 字符及定位字段，不要求中文。因此程序接收层没有硬编码中文短摘限制。

## 发现的缺口

| 位置 | 原约束 | 影响 |
|---|---|---|
| 04/v012 `search_prompt.txt` | 摘要短摘必须为8–45个汉字 | 英文摘要短摘无法按合同提交 |
| 04/v012 `native_response.schema.json` | 题名“原始中文题名” | 对英文原题名形成错误引导 |
| 同一 Schema | 期刊“七刊之一” | 与九刊范围冲突 |
| 同一 Schema | 摘要短摘“中文短语” | 与英文原文短摘冲突 |
| 04/v012 搜索提示词 | 未列出 ASR/AJS 官方入口 | 缺少明确的英文刊方检索路径 |
| v009 `search_prompt.txt` | 已列 ASR/AJS 官方入口，英文可用短语 | 04/v012 不会自动继承该模板，不能依赖 v009 提示词弥补 |

## 已修正内容

- `templates/search_prompt.txt`：明确本轮九刊名单由配置注入；ASR/AJS 必须使用英文刊名和英文主题词；提供 ASR 的 SAGE 官方期刊页与 AJS 的 University of Chicago Press 官方期刊页；要求英文题名、作者和摘要短摘保留原文；中文摘要转述另行提交；检索备注记录实际中英文检索词。
- `templates/native_response.schema.json`：题名改为原始发表语言；作者保留原刊拼写；期刊改为九刊；摘要短摘支持中文约8–45字、英文约5–12词，且整体8–90字符；中文摘要转述保持不变。
- `模块说明.md`：补充 ASR/AJS 英文检索与原文保留规则。
