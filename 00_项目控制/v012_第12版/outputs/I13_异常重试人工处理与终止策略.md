# I13 异常重试、人工处理与终止策略

状态：verified（异常恢复策略与守卫）。

I12八类分类现在对应明确恢复处置：network_failure/model_timeout条件性可重试；executor_unavailable/schema_error/evidence_missing/review_failure/technical_failure需人工；academic_failure/research_failure/budget_exhausted/user_cancelled必须终止当前路径。所有策略automatic_retry=false。网络/超时重试必须保持当前task snapshot有效、原预算余额为正、上一attempt及收据已保留、使用新attempt identity，并获得明确用户授权。缺任何条件即拒绝重试；预算未知或耗尽视为不允许。学术失败不得同题自动再跑或晋级；预算耗尽不得隐式扩额；取消不得自动重启。

I13 guard refinement: non-finite/bool remaining-budget values are rejected; zero/negative original remaining budget returns terminate rather than manual retry. The retry gate cannot treat NaN/Infinity as available budget.
