# G05 验收记录：V15 章节与 06 矩阵来源追溯

## 验收结论

**状态：verified（离线合同与自动化测试通过）。**

G05 要求 V15 的分析章节、经验维度及经验材料来源 ID 能够追溯到本轮 06 已审查矩阵。现有实现及补充回归覆盖了维度身份与顺序、逐章材料范围、空证据拒绝，以及章节来源映射的持久化。

## 实现核验

- `07_三稿独立写作/v015_第15版/tools/writing_plan.py`
  - `reviewed_dimension_sources` 要求矩阵维度 ID 与 V15 理论框架维度 ID 一一对应且顺序一致。
  - 分析章节只能使用对应矩阵维度中、同时通过材料准入的经验材料 ID。
  - 分析章节缺少已准入经验材料时拒绝生成；非分析章节可综合使用已准入材料，但不能引用未准入材料。
  - `reviewed_material_admission` 将章节到经验材料 ID 的映射写入 `chapter_empirical_source_ids`，并同时绑定矩阵、材料回执、审查结果的哈希及研究问题。
  - `produce` 将完整准入凭证持久化到 `writing_plan_review_request.json` 的 `material_admission` 字段。
- `00_项目控制/v009_第9版/tools/resume_writing.py`
  - 原生接续从 `analysis_matrix_reviewed.json` 读取已审查矩阵，再调用 V15 的准入核验与方案生成；不是由独立 CLI 自行授予正式准入。
