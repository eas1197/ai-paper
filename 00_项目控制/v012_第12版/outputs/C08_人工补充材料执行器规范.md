# C08｜人工补充材料执行器规范

状态：verified（文档合同，2026-11-24；不代表真实运行）。

- 统一执行器值 manual；human 为人工提交者类型说明，不另造同义执行器。提交时记录提交者标识（可用授权项目角色或匿名 ID，不强制公开真实姓名）、提交时间（ISO 8601 含时区）、来源类型（上传原文件、公开 URL、访谈转录、人工摘录、其他）、原始路径/URL/定位及使用许可边界。
- 保留原件与实际哈希（确有文件才计算）；人工摘录、转录和说明分别标注，不把转录当作原件。时间未知填 null 并写原因，提交者无法核实不得自称已验证。
- 核验状态分别为 unverified、pending、verified、rejected；默认 unverified。verified 仅指来源和定位经独立检查，不等于学术解释、因果或正式纳入。
- 记录核验者、核验时间、核验依据、失败原因；没有依据不得升级。人工补充不产生 Codex events.jsonl/thread 或 Chat 工具引用，不计为自动搜索完成，不改变原配额/门禁。
- 示例（虚构、不可准入）：executor=manual，submitter=fixture_role，submitted_at=2026-11-24T00:00:00Z，source_type=uploaded_file，verification_status=unverified，formal_eligible=false。
