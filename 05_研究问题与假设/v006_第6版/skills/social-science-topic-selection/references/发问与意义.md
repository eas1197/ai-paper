# 从五刊选题卡归纳出的发问动作

[187 篇论文的逐篇问题与意义](../../../outputs/五刊逐篇审读_20261118_attempt001/187篇选题及意义.md)覆盖五刊的整个锁定馆藏。下列回原文的例子用于定位适用的发问方式。

| 问法 | 何时有研究价值 | 范例及对照 |
|---|---|---|
| 同一制度分环节 | 达到名义目标与产生实际结果的环节可能不同。观察结果足以改变资源投向。 | 《中国高等教育中的自主招生与人才选拔》先问名额给了谁，再问入学以后是否出现选才收益（TSVM4QCW）；《动员效力与经济理性》分开参保广度与缴费深度（FC6Z7KAI）。 |
| 找真正控制机会的一方 | 表面解释集中在个体；岗位、资格或福利实际由组织决定。 | 《趋同与分化》问雇主怎样处理高于岗位需求的学历（L6BXZQIS）；《身份物》把问题放在进入互动之前（GPVBJHXA）。 |
| 同一工具为何兑现不同 | 比较同类制度或工具，只改变可解释差异的情境和执行关系。 | 《基础教育中的学校阶层分割》分开学校的阶层组成与学生自身条件（68HLELIY）；《技术与组织的互构》比较相似 ERP 如何变成不同实际安排（A2PM6EIR）。 |
| 平均改善之后问谁受益 | 总量、相对机会和分布不是一个结果。用事先有理由的群体或阶段。 | 《教育扩张与教育的代际流动性》比较不同阶段和家庭的获益（UJTG4PUK）；《养育差异还是养育陷阱？》区分教养分布与收益（6Z5UHQQG）。 |
| 让意外挑战常规预期 | 可核实的经验与通行预期相反，解释需要新条件或过程。 | 《边缘农户触发的电商村形成》问为何启动者位于村庄边缘（5SKXGHQM）；《隐匿即显露》问平台匿名保护与算法显露怎样并存（J7L9RU78）。 |
| 多种解释面对同一证据 | 两解释可能同时成立，但应说出在哪个条件下预测不同。 | 《中国城市居民的分配公平感研究》比较结构地位与局部参照（LRB6WF8X）；《文化再生产还是文化流动？》比较不同评价环节（CPAIM3Q3）。 |
| 检验概念边界 | 新名称或技术改变了适用条件。明确哪个条件能按实际材料检验。 | 《附身汉字的“字母幽灵”》以汉字经验复查以字母为中心的媒介论（YL9FHT48）；《从网络社会到平台社会》分开连接扩展和权力集中（L66UGTED）。 |
| 把相互冲突的目标拆开 | 目标需权衡，不能用一个总指标宣布成功。 | 《养老还是养小》分析家内时间资源在儿童与老人之间的配置（C39EF39G）；《资源、激励与部门利益》区分征缴部门为什么坚持与不同征管结果（4INKL4GG）。 |

《质性社会学研究的差异性发问和发问艺术》（R6FP8HJQ）提供诊断准则。差异须可靠、信息量可观、预设能成立、解释能竞争且案例有分量。迁移到定量设计时，另外对齐抽样、主要结局、观测时序与因果识别。思辨、短评、质性、述评和定量论文都能教人如何选择问题，但给出的证据强度不同。

## 审查反例

- “教育程度和上网频率有关吗”混合学习、办事、求职和娱乐。即使发现平均差异，也说不清应优先改善接入、协助完成任务还是提供技能支持。
- “派遣工的保障更差吗”把签约对象、法律上的劳动关系、实际保险可得性和理赔混在一起。问卷若只记录是否与派遣或劳务中介签约和受访者报告的工伤保险，问题就只比较这两个可观测事实。
- 在结果可能为零时，先写对哪个实务差异有足够精度。估计区间很宽时，应保留问题和不确定性。
