# 第5步如何运行

项目照常用第04步的 `research.py run --input … --run-id … --stage both` 运行 04→05。已有同 run 的 04 attempt 时，在输入 JSON 的 `05.upstream` 填入其 `stage_manifest.json`，用同命令的 `--stage 05`。输入资料、04 检索和既有字段参照[04 数据契约](../../04_议题文献与现实/v007_第7版/数据契约.md)。

## AI 的顺序

1. 先读取新 05 attempt 的 `question_learning.json`，按其中锁定的 [选题 Skill](skills/social-science-topic-selection/SKILL.md) 对读相关的逐篇选题卡、精核范例及开篇候选。说明原问题的现实观察、理论预期、有效对照、实际意义和证据边界。题名和词语命中只用于定位，回查之后才能判断。
2. 接着读 `reasoning_tasks.json`，按四路推进形成候选。候选以当次 04 的证据为依据。记录迁移了哪种提问动作以及为何适用，并比较最简单的替代问法。
3. 将逐题审查填入 `05.annotations` 对应 JSON 的 `significance_reviews`。在后续 05 attempt 提交，G5 在正式冻结前校验内容和证据。模板见[选题审查记录](templates/significance_review.json)。项目内 AI 可直接执行上述读写顺序；显式注入已有 `model_provider` 时，执行器按顺序送交范例、生成候选并复审，模型输出先留在 `model_proposals.json` 等待核实。

## 逐题审查字段

| 项目 | 必须回答的问题 |
|---|---|
| 现实 `reality` | 哪群人，在什么场景遇到什么可观察的问题，与什么相比，范围和后果是什么？ |
| 理论 `theory` | 哪个既有解释留有哪条未区分的预测，研究答案会如何修正这个解释的边界？ |
| 实际 `practice` | 哪个人或机构能用结果，具体要做什么决定，会产生什么后果？ |
| 政策 `policy` | 政策原文设定了什么目标，执行中遇到什么取舍，结果能支持哪项判断？如缺少直接应用，在 `bounded` 写明证据能抵达的边界。 |
| 用途 `answer_use` | 更简单的问法是什么，这道题增加什么信息？支持预期、支持竞争解释、可排除有实务意义的差异、现有证据不足，分别会怎样处理？ |

候选 `accepted` 对应审查 `pass`。每类意义须有判断；前三类和声称适用的政策判断都须有 04 直接证据 ID，政策证据须指向 04 已归档的政策上下文。政策使用边界还须复核，原 G5 引言政策要求仍适用。用途和范例迁移要具体，且写出借用的动作及边界。候选 `needs_evidence` 对应 `revise` 并说明下一步，`rejected` 对应 `reject`。逐题审查进入 G5 内容哈希，接受研究设计仍须具名复核。

## 单独检索或刷新资源

从项目根目录查询187篇逐篇审读卡片。

```powershell
python '.\05_研究问题与假设\v007_第7版\tools\topic_cards.py' retrieve --theme '灵活用工 劳动力市场分割 社会保险 征缴 工伤保障'
```

在项目根目录执行下列命令即可为任意主题准备提问范例。主题由当前研究任务填写。

```powershell
$tool = '05_研究问题与假设/v005_第5版/tools/question_library.py'
$library = '05_研究问题与假设/v005_第5版/outputs/五刊提问资源_20261118_attempt002/question_library.json'
python $tool retrieve --library $library --topic '教育机会与数字不平等'
```

`scan --output <新资源目录>` 仅读取本地 Zotero；需要 Python 和 pypdfium2。扫描后回查原文，保存审读 JSON，再用 `publish --output <资源目录> --annotations <审读JSON>` 锁定新资源。确认覆盖、出处和检索后，更新 00 配置中的快照路径和 SHA-256。常规运行直接使用已登记版本。
