# 05 研究问题与假设 · 第1版

从可追溯文献与现实的对话产生同层级、可证伪、可由数据回答的研究问题和假设。

前置必读：根目录AGENTS.md、基础要求.md、项目架构.md。本模块框架已建立；业务状态为planned，除非明确的业务验收报告证明完成。

## 输入

04关系图谱、核心25篇全文对话矩阵、政策/新闻、数据可行性初筛。

依赖模块：04。

## 输出

- 候选问题与四路缺口卡
- 同层级检查和反证记录
- 主/竞争假设与DAG
- 冻结研究设计和后续变量需求

标准产物名称：`gap_cards.csv`、`hypotheses.json`、`dag.md`、`analysis_design.json`。

## 处理流程

1. 建立主题→议题→问题树，问题必须说明对象、关系、单位、时间与比较，不以政策口号替代可检验问题。
2. 四路并行构思但不强行每路都成立：①现实情境与现有解释张力；②同层级未覆盖机制/变量；③适用条件扩大或缩小；④原有关系的方向、形式、机制或解释修正。
3. 每个缺口绑定原文献和页码，给“原研究说了什么—本文改变什么—为何不是换名重复—何种证据能否定”。不能仅因100篇没出现就断言学界空白。
4. 同层级审查同时检查抽象层、个体/家庭/学校等单位、X/M/Z/Y角色、时间顺序与解释维度。上位概念与下位指标先作映射，不能并列当新机制。
5. 围绕同一问题形成主假设与竞争假设，写预期方向、机制、边界、反证、替代解释和变量需求；生成DAG决定控制集，不把已有文献的全部控制变量照搬。
6. 用CFPS/CGSS元数据预检关键变量、波次和时序。不满足测量或识别则收窄问题/改设计，不能进入分析后才换成“显著”的问题。
7. 冻结研究问题、主结局、假设族、主模型、排除/缺失/权重、推断目标与稳健性计划；研究者尚未裁决的实质判断保留pending，不能代为接受。
8. 后续06有新发现则追加偏离日志并区分探索性分析，必要时回到04补证。

## 验收标准

- [ ] 每个主假设有直接全文对话及反证
- [ ] 同层级审查完成，概念不重复/错层
- [ ] 关键变量和时间顺序初步可行
- [ ] 设计冻结状态真实，不伪造研究者裁决

## 失败与恢复

输入不可用、证据不足或访问受限时记录明确状态与缺口，保留已验证产物；不能造数据或跳过硬门槛。上游内容改变则本模块产物stale，重新锁定输入后建立新attempt。事实性错误回到产生该事实的上游修正，不在写作层掩盖。

## 假设卡最小内容

`hypothesis_id, research_question, gap_type, baseline_paper_ids, evidence_ids, baseline_relation, proposed_change, same_level_checks, X, Y, M, Z, unit, timing, mechanism, scope, expected_pattern, falsification, competing_explanations, dataset_feasibility, causal_claim_level, review_status`。
