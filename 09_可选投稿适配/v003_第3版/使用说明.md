# 投稿模块使用说明

Python3.10+，仅标准库。先阅读01调查报告，当前G1未通过时prepare会拒绝抽样。

```powershell
python .\09_可选投稿适配\v003_第3版\tools\submission.py prepare --input .\09_可选投稿适配\v003_第3版\templates\workflow_input.json
python .\09_可选投稿适配\v003_第3版\tools\submission.py status
```

示例enabled=false只返回skipped。实际启用填run_id、family_id、模式、07/必要时08的stage_manifest、已验收01资源路径、上游锁定稿件、输出attempt、种子、资格评估、当日目标刊复核以及逐刊材料与核对记录。原稿、事实和结果不得为适配而变造。

```powershell
python .\09_可选投稿适配\v003_第3版\tools\submission.py validate --attempt <本项目内材料目录>
python .\09_可选投稿适配\v003_第3版\tools\submission.py transition --id <submission_id> --state rejected --evidence <回执证据JSON>
python .\09_可选投稿适配\v003_第3版\tools\submission.py send --package <该刊package.json> --approval <具体外发核对JSON> --smtp-config <SMTP配置JSON>
```

最后一条才会外发，当前没有执行。smtp-config只放服务器、端口及环境变量名，不放密码。程序仅支持SMTP_SSL；系统投稿使用官方系统材料交接，注册和验证码不能自动绕过。

审批content_sha256必须与package一致，正文、收件人、附件变化会失效。所有材料检查和目标刊当日复核完成才可ready_to_send。发送结果不明时持锁；核对编辑部回执或发件记录后用有证据的状态修正，不能以经过若干天自动转投。未发送旧队列可通过superseded并记录原因替换；在审队列不能这么处理。

资源/代码/输入改变会stale，使用新attempt；准备新队列不会重置旧在审记录。技术测试中的合成稿件与假回执不会进入真实台账。
