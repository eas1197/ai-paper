## 阅读与验收口径

审读者为Codex（AI）。审读完整PDF中的方法、对应实证表格及相关前提/限制，不以摘要或关键词命中冒充阅读；不声称校勘全文每句或全部证明。fulltext_read在本资源中表示这一明确范围的全文方法审读。精确页码统一为从1开始的PDF物理页，不混同期刊印刷页；英文作者稿页码只对应本地作者稿。

passed只表示本方法资源的配对、内容自查、文件/页码/短摘与哈希检查通过。内容自查与建设由同一AI完成，未经过独立人工方法专家审稿。该状态不是具体研究G6通过，不使第2/3步或第4步25核心文献自动通过。

原理来源含期刊方法研究、1篇技术研究报告和1篇会议方法论文；不是全部“经典奠基论文”。二元logit原理从Yee分类模型的两类别特例导出，已标为系统推导。ZIP实证范例确实估计ZIP，但没有完整双分量参数表；现有后验风险结果表与本库新增报告模板分开记录。

## 证据与建议分层

题录、PDF定位、实际表格结构：直接证据。诊断与报告规范：跨文献综合及系统建议，不倒推范例已经全部实施。面向CFPS/CGSS的迁移：明确适用范围的系统推断。原文未报或本次未核实的项目记未知。
