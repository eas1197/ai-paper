# 筛选排除与纠错

核验日期：2026-11-15；定位以冻结references中的PDF物理页为准。

| 项目 | 处理 | 理由或修正 |
|---|---|---|
| Fox、Weisberg复杂调查教材附录 | 仅work辅助资料，不计两篇代表文献 | 教材附录不能替代本项目要求的研究文献；改用Lumley与Oberski实际研究 |
| 本地7IPHTLL6论文 | 不计面板固定效应范例 | 使用行业等固定效应不能冒充同单位跨期固定效应；选HRS个人—波次模型 |
| 刘欣、胡安宁2023 | 用于OLS，未用于嵌套系数比较 | PDF15–16模型样本量不同；嵌套卡改选共同N的CEPS表3 |
| 许丹红、桂勇2023 | 保留表式，标注解释问题 | PDF13–14的1−OR不是概率下降比例；PDF8未报完整插补算法与合并细节 |
| 石金群等2026 | 只将表2模型1/3/4/5作为有序模型 | 同表模型2为多分类模型；替换估计器不等于比例优势检验通过 |
| 石智雷、杨云彦2012 | 家庭与个人单位分开 | PDF8家庭策略定义绑定表3，不能用个人参照解释家庭对照 |
| Kleiber、Zeileis2016 | 计作NB范例 | 补充表2比较单NB和混合NB；混合成分不等于结构零 |
| Junming Li等2020 | ZIP模型与风险结果表分开 | PDF5是ZIP模型，PDF10是风险分类表；PDF12决定因素表是另一个模型，不能冒称ZIP双分量参数 |
| 杨文娟、李黎明2023 | 只抽取中介报告结构并保留警示 | PDF6表5总中介系数/区间与叙述不一致；不同检验结果不可择显著者，不移植原数值 |
| 张海东、袁博2024 | 选择依据与绝对拟合分开 | PDF13–14将p=.001称不显著有误；BIC较小不意味着局部独立/绝对拟合均通过 |
| 魏万青2012 | 匹配推断与尺度另核 | PDF11的Bootstrap策略不能自动适用于所有最近邻匹配；对数系数不能直接当百分比 |
| 周葆华、赵鹿鸣2024 | 标准化、随机初值记未知 | PDF7–8存在不同量尺，未核实标准化和多初值，库中列为新研究必须补查 |
| 英文DID作者稿 | 发表年与文件版分列 | Callaway/Sant’Anna及Sun/Abraham本地稿为2020，发表年2021；页码绑定当前PDF |
| 失败/非PDF的外部下载 | 保留失败日志，不计覆盖 | 未绕过403、验证码或登录；Lumley/Scott等失败候选不计已读全文 |

这些问题并不由文件短摘检查自动发现。本版逐项记录方法层面的判断；它们限制可复用内容，不能被passed状态抹去。
