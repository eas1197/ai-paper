# 定量社会学研究与写作项目

## GitHub 阅读快照

本仓库用于在 ChatGPT 中查阅项目框架、模块版本、代码、模板和研究进展。研究原始数据、论文全文及提取文本、逐次运行明细和浏览器缓存保存在本地。部分证据链接指向本地材料，核验研究结果时请回到本地项目。

全项目采用 TRACE 管理。基础要求为第5版，项目架构为第6版，启用模块以控制模块第5版注册表为准。

## 控制工具

Python 3.10+，仅标准库。在项目根目录运行。

```powershell
python .\00_项目控制\v005_第5版\tools\project.py validate
python .\00_项目控制\v005_第5版\tools\project.py trace
python .\00_项目控制\v005_第5版\tools\project.py plan --writing-mode single
python .\00_项目控制\v005_第5版\tools\project.py plan --writing-mode three_plus_review
python .\00_项目控制\v005_第5版\tools\project.py init --run-id my_study
```

无题启动先返回选题任务。完成选题后用 `--topic-decision` 创建工作区并绑定裁决记录。给定主题时可沿用 `--theme` 与可选 `--issue`。实际关卡由对应模块复核放行。
