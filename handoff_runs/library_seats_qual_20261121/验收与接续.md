# 图书馆座位试验验收与接续

以制度可识别性为核心概念。与用预约份额解释公平的近邻研究对话，提出证明门槛及情境例外与纠错权两个维度。两维可以同时出现，分别回答什么信息算作有效使用，以及认定冲突时谁可改判。理论增量暂为待论证主张。

初查和框架定向收集各执行一批，各保存 5 个原生网页事件和 8 条材料记录。各批存在同源或跨批重复，不能加总为 16 份独立证据。矩阵保留了现场刷卡和系统内置暂离、补签等反例。规则可说明允许什么，报道中的自述可提出冲突，均不足以推断误判频率或申诉成功率。

经总控真实生成六章实验写作方案。首次接续发现 06 和 07 对框架 JSON 的规范化方式不同，已让 07 按 06 的格式核对指纹并复测成功。06 与 07 各 2 项测试通过。历史进阶课程案例原材料与判定保留。
