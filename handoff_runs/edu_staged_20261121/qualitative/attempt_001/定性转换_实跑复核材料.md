# 进阶课程机会 · 定性转换验收材料

源题和文献继续来自 `edu_staged_20261121`。核心问题为“稀缺教育机会的配置规则如何决定机会扩展能否缩小不平等？”旧问题比较两种准入规则对机会差距的影响，需要可链接的规则、学生资格、背景和实际分配。新问题为“自动入读如何改变学生争取进阶课程机会的过程？”关注哪些行动由学校完成，家庭还需要在哪些环节行动。沿用有效维持不平等的理论关切，以既有华盛顿准实验所见的入读结果为对话对象，经验任务是限定在可追溯案例中辨别进入之后的选择，避免把公开报道当总体分布或因果识别。

## 可核验材料及限制

真实 CLI 一批返回七条带网页事件凭证的记录。原始事件及答复哈希、时间、材料性质、对象、上下文、定位、关系及限制见 `material_receipt.json`。以下是审查重点。

| 材料 | 能支持的论证 | 边界 |
| --- | --- | --- |
| KUOW 公开访问，学生课堂经历 | 报道所载学生直接叙述可确认有学生在排入课程后才判断是否继续。 | AP 世界史，跨学科对照。关于同学退出是转述，未见退出表或改班记录。 |
| WUNC 公开访问，家长经历 | 改革前一则家庭叙述呈现家长发现被遗漏并主动交涉的过程，显示旧入口可能要动用家庭资源。 | 涉及资优认定，不能直接与同条件数学学生或明确后来符合阈值者对照。 |
| Education Week 记者报道 | 学校同时改变准入、先修要求、课程供给或成本支持，提供有意义的竞争解释。 | 属报道与机构回应，未见可追踪的家庭选择。 |
| 华盛顿州与北卡州规则 | 确认不同资格标准、默认安排和退出制度。 | 规范事实，与个案是否落实分开。 |
| Bothell 与 Tacoma 学校公开指南 | 核实学校对咨询、注册和退出手续如何公开说明。 | 网页详略不同，不把缺少说明编码为缺少程序。 |

拟形成三个分析维度。第一，资格识别及默认排课由谁启动。第二，告知、咨询和不同家庭能否有效选择。第三，退出及真正入读，对照课程供给、费用和先修条件等其他变化。只以报道中已发生的行动举例；政策条文说明制度机会；前两者和研究者解释分开。可继续的最低范围是有边界的公开案例对照，用来检视说明哪些环节可能前移、哪些仍有摩擦，不估计群体差距或声称比较两州净效果。若连该范围也不足，应保留失败结论并启动教育新实验。

公开材料只存来源定位与脱敏转述，访谈为二手材料，研究者没有接触受访者。学校指南为公开网络文本，无参与观察，也不称为网络民族志。经验材料不计入学术初查和补查的数量。
