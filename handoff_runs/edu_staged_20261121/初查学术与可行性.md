# 教育初查 · 概念化、反诘与数据预检

唯一主题输入为“教育”。初查显示，教育机会的扩张与教育阶段内优质机会的分配可以呈现不同方向。ASR 的八年级数学分配研究明确区分了学校是否开设进阶课程和学生在校内是否得到课程名额。中国关于教育扩张的研究讨论了从基础教育普及到后续升学关口的差距。不同国家和学段不能直接合并比较，只用于识别共同的制度过程。

- 现象与概念。学校是否开课衡量可接近的课程供给。学生获分配反映准入结果。教师推荐、资格线和实际修课分别反映准入规则、资格和行为，三者不可互换。
- 核心学术问题。稀缺教育机会的配置规则如何决定机会扩展能否缩小不平等？
- 初始问题。学校普遍开设同类进阶课程后，弱势学生获得进阶课程的机会差距是否缩小？
- 已有解释与反诘。有效维持不平等预测分层可能迁移至同一阶段内部。ASR 近邻已实证拆分校际供给和校内相对排序，因此再分解一次不能单独构成增量。真正需要区分两种准入逻辑：达到明确标准后默认进入，和达到标准后仍需教师推荐、家长申请或校内名额竞争。
- 深化问题。在学校普遍提供进阶课程时，按明确标准自动安排和仍需推荐或申请，是否使原先的校际机会差距在校内以不同方式延续？如果差异主要跟随排序变化，应随名额或校内成绩分布变化；如果裁量或额外申请制造进入门槛，在相近资格的学生之间仍可能观察到差距。规则本身可能由学校资源和学生构成决定，未经设计不能声称因果。
- 数据预检。需要可链接的课程目录、政策实施时间、资格、推荐或申请、实际分配与学生背景。不以修课结果倒推准入规则。NCES HSLS:09 可公开获取学生成绩单派生指标，但完整校级开课记录属于受限补充数据，且推荐或默认安排的规则能否取得、对课程类别和学校进行联结，以及使用权限均未确认。中国 CFPS 历史字段核验仅支持区分就读阶段与普职类型，未观察逐校课程规则。

文献及理论使用本轮 `initial/literature_matrix.json` 和 `initial/theories.json`。数据预检的 [NCES 数据说明](https://nces.ed.gov/pubs2015/2015036.pdf) 与 [公开和受限数据说明](https://nces.ed.gov/surveys/hsls09/faq.asp) 单列，只核查可行性，不用于扩大初查论文集合。
