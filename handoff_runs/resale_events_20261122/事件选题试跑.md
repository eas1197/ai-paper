# 二手平台纠纷 · 事件选题试跑

现实预期是材料、请求与标准都相同时，同一纠纷的判断应较稳定；报道出现群审与平台复核结论不同。初解是新证据纠正了初审遗漏。独立反方指出，相同材料未证实，须区分新证据、材料呈现、举证责任、处理目标与公开案例选择。由此形成候选问句“二手交易争议中，群审与平台复核如何界定什么材料算证据？”反方不作放行。

九刊实际初查 1/5，《管理世界》文章主要解释电商平台监管中的组织学习，只作制度背景。理论材料单列：Akerlof解释交易前商品质量信息不对称，不能单独解释纠纷后的裁决反转；Tyler 的程序正义解释当事人如何评价处理，也不能凭满意程度倒推出裁决标准。刊外近邻刘子檀已讨论小法庭的叙事博弈与证据效力，因此仅研究“买卖双方怎么举证”难以建立增量。可区分的后续问题是：**平台纠纷的处理层级如何改变证据的证明力？** 若拿不到两轮原始材料和理由，应把经验问题限定为当事人如何理解证明力变化，不把叙述当成平台机制。[刊外近邻原文](https://pdf.hanspub.org/ecl_2314261.pdf)

核心概念暂定“证据的制度承认”。从它推导两个可同时出现的维度：哪些材料能够被当前处理主体读到并作为证明；材料存在时，谁须证明何种责任及什么证据达到门槛。两者分别涉及可见性与判准，未按交易流程划分。两维差异目前是待检验的机制命题。

| 定向平台 | 实际结果 |
| --- | --- |
| 豆瓣 | 找到可打开的平板纠纷和经验帖；前者作为当事人叙述，后者仅用于理解举证习惯。 |
| 百度贴吧 | 找到卡牌纠纷的卖家说法；热门页重复展示同一内容，只计一个事件，不把它当平台记录。 |
| 知乎 | 命中经验与教程，未核实到可追溯的双阶段事件。 |
| 小红书 | 命中电商规则，未核实到相关亲历事件；规则不计入事件。 |
| 小黑盒 | 本次域名定向查询未取得可核查的相关事件。 |
| 微博 | 有转载和说法线索，部分正文受 robots 或登录阻挡，未据摘要补写事件。 |

事件包保留四个独立事件，按具体事实判定。二手包报道显示群审与后续处理不同，但证据是否相同及最终是否退款未知；相机报道支持平台公开表达责任排序，不能据此确认视频内容或真实损坏原因；两个论坛事件仅支持当事人如何理解证明。排除两条单方关键陈述后，仍可研究可见的公开判断差异和平台公开给出的理由，不能归纳稳定的改判机制或经验理想类型。相关资料已脱敏转述，未进行网络民族志。
