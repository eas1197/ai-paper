# 期刊库使用说明

Python3.10+，主程序仅标准库。补充目录下载脚本使用requests/pdfplumber，不是主运行的必需依赖。

```powershell
python .\01_投稿期刊库\v003_第3版\tools\journals.py build --input .\01_投稿期刊库\v003_第3版\assets\survey_20261116\survey_bundle.json --output .\01_投稿期刊库\v003_第3版\outputs\survey_20261116_attempt001
python .\01_投稿期刊库\v003_第3版\tools\journals.py validate --resource .\01_投稿期刊库\v003_第3版\outputs\survey_20261116_attempt001
python .\01_投稿期刊库\v003_第3版\tools\journals.py export --resource .\01_投稿期刊库\v003_第3版\outputs\survey_20261116_attempt001
```

build保留未完成结果并返回退出码1；这不是程序异常。export仅在G1通过时返回可发布快照。路径存在时拒绝覆盖，修改证据后使用attempt002。根配置的资源指针由本轮激活脚本指向实际快照；旧运行保持原绑定。

`tools/assemble_survey.py`将本轮网页工具归档转换为字段证据；属于机器抽取待复核。URL列表只收有来源线索的官方页面，搜索结果和第三方代理保存在searches/leads中，不纳入官方证据。原始网页内容不执行，登录页、验证码页和失败页不当作稿约。

补证时按journal_id修订新输入包，逐项补充来源、证据定位及文件哈希。官方未公开的影响因子、费用、本科生政策仍记未知；近期定量稿件只能支持方法适配，不能支持本科生友好或录用概率。投稿前只核对目标十刊的动态信息。
