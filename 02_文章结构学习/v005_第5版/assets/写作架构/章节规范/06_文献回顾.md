## 6. 第二部分：文献回顾，2400字，组织2—4条主要解释路径

本节的主线是：**概念与关系范围 → 主要解释路径及各自证据 → 路径之间怎样联系 → 原有解释尚未充分覆盖什么 → 本文进入的位置。**分歧、反证和边界在确有材料时展开，不作为每篇都必须制造的收尾。

### 6.1 总预算与可变段落

| 论证单元 | 字数 | 先后任务 |
|---|---:|---|
| L0 概念与关系范围 | 240 | 说明议题中的核心关系、概念和分析单位，区分同义词与不同角色 |
| L1—Lk 主要路径，k默认2—4 | 合计1440 | 每条路径说明命题、逻辑链、代表证据、适用范围与尚待解释处 |
| LR 路径联系与综合 | 240 | 说明并列、互补、递进、嵌套、共同条件或竞争，得到现有解释图谱 |
| LG 理论待推进处 | 300 | 优先定位实际空白；按问题需要说明现实张力、范围调整或关系修正 |
| LP 本文理论位置 | 180 | 明确本文接续哪一关系、补充哪一环节，转入第三节 |
| 合计 | **2400** | 路径数量和段数随文献变化，不固定八段 |

两条路径时每条约720字，可分两三段；三条时每条约480字，可分两段；四条时每条约360字，可用一至两段。它们不必等长：与本文直接对话的路径写足，提供背景或共同前提的路径写短。1440字的合计预算保持，除非在整篇预算中显式调整。

### 6.2 每条解释路径的内部结构

默认顺序：

1. **命题**：这条路径用什么因素、过程或条件解释什么结果。
2. **逻辑**：X→Y、X→M→Y、X×Z→Y，或其他形式；说明概念角色。
3. **证据**：代表研究在什么对象、资料和设计中得到什么判断。
4. **范围**：覆盖哪些群体、地区、时期、制度、阶段和测量。
5. **衔接**：与下一条路径的关系，以及对本文问题已解释到哪里。

不是每条路径都要单独宣布一个空白，更不能将所有路径批评一遍再声称本文全面替代。可以先说明几条路径共同取得了什么认识，最后集中提出一个关键空白。

原创句序：“【路径名称】将【结果】理解为【核心因素或过程】的产物。其主要逻辑是【关系链】。在【对象与设计】中的研究发现【有限而准确的判断】。这些证据解释了【覆盖部分】，并为理解【下一环节】提供了基础。”只有确有材料时，再补充反例或范围限制。

### 6.3 路径之间不默认并列

| 关系 | 怎样组织文字 | 原创衔接表达 |
|---|---|---|
| 并列 | 先说明共同结果，再比较不同解释维度 | “围绕同一结果，另一类研究强调……” |
| 互补 | 说明各自解释不同部分，合起来形成较完整认识 | “上述解释揭示了资源条件，另一条路径进一步说明这些条件如何转化为行动。” |
| 递进/过程连接 | 按过程次序写，前一条路径的结果成为后一条的起点 | “在解释机会如何分配之后，后续研究转向机会怎样转化为最终结果。” |
| 嵌套 | 先给上位框架，再写其中的具体机制，不重复计为同层级因素 | “在这一资源框架内部，相关研究进一步区分……” |
| 共同条件 | 先说若干路径，再说明共同依赖的制度前提 | “这些机制虽各有侧重，但其发挥均受到……条件约束。” |
| 竞争/修正 | 准确列出不同预期，说明哪些证据可以区分 | “对于同一比较，两类解释分别预期……。” |

可以一篇内同时有多种关系。例如两条资源路径并列，一条转化机制与它们递进，另一条制度条件调节其作用。正文可以据此采用“资源—转化过程—制度条件”的二级标题，不必逐条命名“解释一、解释二”。

### 6.4 空白怎样提出

先回答：在已经建立的关系图谱中，缺的是同层级因素、某段过程、因素组合、作用条件，还是关系形式？然后说明为何遗漏它会影响对议题的理解。最后绑定具体核心全文和页码，解释本文怎样与原命题接续。

“尚未在某地区研究”只能是对象差别；只有该地区体现了明确的制度或条件差异，并能改变命题预期时，才可能构成理论推进。“没写家庭”也须核对其是否已通过经济、文化、投入等概念被覆盖。

若推进为G3，则明确原范围和拟扩缩范围；若为G4，则明确原方向、形式或过程以及拟修正内容。它们都可以成为本节末尾，不要求改写成学术分歧。若全文核查发现候选空白已被覆盖，撤销该缺口卡并另寻问题，不能换词保留“创新”。

### 6.5 25篇核心文献怎样分配

为每条路径配置代表性全文证据，另为综合、空白核查、反证和讨论保留来源。数量随路径实际重要性分配，不采用每条必须相等的配额。一个核心文献可在不同位置承担不同角色，但每次引用都要支持相应判断。

工作台账保存paper_id、原命题、逻辑关系、适用范围、证据定位、本文回应和拟引用位置。正文按照论证需要引用，避免在段末堆一串作者替代解释内容。100摘要用于初步图谱，25核心全文才为具体理论对话提供实质支撑。
