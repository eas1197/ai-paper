# 两刊写作资源验收与复现

## 核验范围

两篇官网刊页来自第05步已保存的完整逐行回收文本，与两刊135篇本地 Zotero PDF 一同列入[输入清单](输入清单.json)。135篇原 PDF 的题录页、正文、引文表与卷末附页分开标记。有同一条文献的重复附件时使用一份定位稳定的原件。英文提要和同一期其他稿件保留于页账。

读入材料保留逐页输入的 SHA-256。原文位置按 PDF 文件的页序记录。两篇官网补取文本沿用对应的刊页资料和哈希。文字层不足的表页见[版面补读](../两刊全篇分析_20261118_attempt001/版面补读.md)和[五刊原图复核](../../../../05_研究问题与假设/v006_第6版/outputs/五刊逐篇审读_20261118_attempt001/表格缺页复核/复核记录.md)。

## 读入、复核与使用

- 本地 Qwen3-4B 接收全文所列页内容，按页保存承接、推进、后续处理和表达。先复读20篇定量论文，余下篇目用精简配置。具名证据位置以短锚与源页字面匹配检查。匹配说明文字位置可查，原文解释仍须逐条核对。
- 定向选取两刊20篇定量论文。从开头至结尾回查各节的推进，逐句核94个摘要句，手册引用相应原页。篇幅分布按文本提取估算。
- 原有几何分段索引提供正文自然段的候选定位。本地 Qwen2.5-1.5B 逐候选段读取文字及相邻短语，生成段落功能候选。原文校对发现，有明确假设编号的段落被归为研究背景，表格也可能被归为结果段。将这些原文校对单列。附项、错切、缩进、段落合并等情况看[复核队列](paragraph_review_queue.csv)。功能分数表示模型在给定标签间的相对值。
- [语言范例](../../../../03_学术语言学习/v005_第5版/outputs/两刊语体学习_20261119_attempt002/语言范例手册.md)选用上下文经过原文核查的段落。原创试写单独保存。写作检索测试使用现行第07步的真实代码。

G2仍需逐段精校及审核。G3正式发布依赖上游验收。候选索引可在本机按段落功能查用。

## 复现

在 E 盘项目根目录运行。设定临时目录和 Python 缓存位置，模型复用 E 盘已有权重。脚本逐篇保存产物。成功记录与输入锁一致时自动跳过。全部使用本地推理。

1. 先用 review.py 的详细配置。将范围设置为第1至20篇。
2. 再以 review.py 的精简配置处理尚无记录的篇目，分块限制为27,000字符。单篇失败时调整分块重试。错误记录保存在 work。
3. 用 paragraph_read.py 核对20篇的段落索引，再运行 assemble.py 检查篇目、输入页、锚点及原件哈希。
4. 用第03步的 build_examples.py 锁定本轮范例、说明和试跑记录。

当前数据更新是一轮公共资源候选建设，模块版本仍由项目注册表确定。
