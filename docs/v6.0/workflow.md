# ai-paper 6.0 流程与分支说明

研究与写作

6.0 只走 Codex 路径。原 3.x 负责选题、筛选和方法判定。两种研究方法各自完成分析，共用 main 的语言库和第七步写作。独立反诘和学术审查沿用原来调用另一个智能体的方式。

| 环节 | 工作与交付 |
| --- | --- |
| 3.x 选题与初查 | 现实观察、事件核证、独立反诘、文献初查，提出候选研究问题。 |
| 初审与设计审查 | 由独立智能体判断学术价值和研究增量，核查证据可得性与方法适配。定量不适用时评估定性。 |
| 文献补查 | 学术初审与可行性通过后，围绕已明确的问题和设计补检，与初查合并去重。 |
| 终审与 S08 | 独立复核问题、合并文献、理论及可行性。通过后冻结研究设计和方法，按原规则处理返修或归档。 |
| 定量 | 获取与处理数据，使用 Stata 分析，交付样本、变量、结果表图及证据定位。 |
| 定性 | 获取与整理材料，开展经验分析，交付经验矩阵、主要发现、反例及证据定位。 |
| main 第七步 | 两路使用同一写作入口和 main 语言库。按方法生成写作任务，完成正文、独立审查、返修和复验。 |

现有 V14 的正式入口按定量证据检查，要求 G4–G6、模型结果和表图。接入定性时，由同一个第七步接收定性材料与经验矩阵，并按定性规则检查写作证据。S08 提供冻结设计与方法，写作仍需对应的分析产物和门禁证据。
